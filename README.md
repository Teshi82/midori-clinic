# みどりの丘クリニック（架空）

内科クリニックを想定した、ポートフォリオ用の静的Webサイトです。実在する医療機関・医師・住所・電話番号とは関係ありません。

## 重要な注意

- 電話、WEB予約、地図はデモ表示です。実際の発信・予約・送信は行いません。
- 診療内容、診療時間、院長名、所在地などはすべて架空または掲載例です。
- 医療機関サイトとして使用する前に、医療従事者・法務や広告表現に詳しい専門家による確認が必要です。
- 架空サイトが実在施設と誤認されないよう、`noindex, nofollow` と `robots.txt` で検索対象外にしています。

## ファイル構成

```text
clinic/
├─ index.html                    トップページ
├─ privacy.html                  プライバシーポリシー掲載例
├─ styles.css                    デザイン・レスポンシブ対応
├─ script.js                     メニュー、FAQ補助、デモ画面、アニメーション
├─ robots.txt                    検索エンジンの巡回を抑制
├─ README.md                     このファイル
└─ assets/
   ├─ clinic-consultation.jpg    AI生成の架空イメージ写真
   └─ favicon.svg                サイトアイコン
```

## ローカルで確認する方法

ビルドやパッケージのインストールは不要です。

### 最も簡単な方法

1. `index.html` をダブルクリックします。
2. ブラウザでトップページが開きます。
3. スマートフォン表示は、ブラウザの開発者ツールで画面幅を変更して確認します。

### ローカルサーバーを使う方法

Pythonが利用できる場合、PowerShellでこのフォルダに移動し、次を実行します。

```powershell
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。終了はPowerShellで `Ctrl + C` です。

## 実装した機能

- 画面幅920px以下で切り替わるハンバーガーメニュー
- `Escape` キー、背景クリック、フォーカス循環に対応したモバイルメニュー
- CSSによるスムーズスクロール（動きを減らすOS設定では無効）
- HTML標準の `details` / `summary` を使ったキーボード対応FAQ
- `IntersectionObserver` を使った控えめなスクロール表示
- 実送信しないWEB予約・電話・地図のデモダイアログ
- 見出し構造、スキップリンク、フォーカス表示、表の説明などの基本的なアクセシビリティ
- 相対パスのみを使ったGitHub Pages対応
- 外部フォントや外部JavaScriptを使わない軽量構成

## デザインの調整場所

色は `styles.css` 冒頭のCSS変数でまとめて変更できます。

```css
:root {
  --color-primary: #1f6a52;
  --color-pale: #edf6f0;
  --color-accent: #c68546;
  --container: 1180px;
}
```

- `CSS` は色、余白、レイアウト、スマートフォン表示など、主に見た目を担当します。
- `JavaScript` はメニュー開閉、FAQの開き方、デモ画面、スクロール演出など、主に操作を担当します。

## 画像について

`assets/clinic-consultation.jpg` は、この架空サイト向けにOpenAIの画像生成機能で作成したものです。実在人物・実在施設・ロゴ・読める個人情報を含めない条件で生成し、Web表示用にJPEG品質86で圧縮しています。

画像の表示サイズは `1672 × 941px`、現在のファイルサイズは約150KBです。HTML側に幅と高さを指定し、読み込み中のレイアウトずれを抑えています。

## 実案件へ変更する前の確認リスト

1. クリニック名、所在地、電話番号、交通案内を正式情報へ差し替える。
2. 院長本人の許可を得た写真・氏名・経歴・資格だけを掲載する。
3. 診療範囲、対象年齢、発熱時の受診方法、受付終了時刻を医療従事者へ確認する。
4. 健康診断・予防接種の種類、対象、費用、予約条件を確認する。
5. 医療広告ガイドライン、個人情報保護方針、外部予約サービスの規約を専門家と確認する。
6. 問い合わせ・予約を実装する場合は、送信先、暗号化、保存期間、削除方法を決める。
7. 正式公開が承認された場合のみ、`noindex` と `robots.txt` の設定を見直す。
8. 実機・主要ブラウザ・支援技術で最終確認する。

## GitHub Pagesで公開する場合

公開操作はまだ行っていません。公開前に、架空サイトである旨と検索除外設定を再確認してください。

1. GitHubに新しいリポジトリを作成します。
2. このフォルダのファイルをリポジトリ直下へ追加します。
3. GitHubの **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、`main` ブランチの `/ (root)` を指定します。
5. 公開URLが発行されたら、PC・スマートフォンで表示とデモ動作を再確認します。

相対パスで実装しているため、通常のGitHub PagesプロジェクトURLでも動作します。

## 主な動作確認項目

- 320 / 375 / 768 / 1024 / 1440pxで横方向のページあふれがないこと
- メニューがクリック・キーボード・`Escape` で操作できること
- FAQがマウスとキーボードで開閉できること
- 予約・電話・地図ボタンが外部送信せず、デモ案内を表示すること
- 診療時間表が320px幅でも画面内に収まり、記号の意味が読めること
- JavaScriptが無効でも本文と主要リンクを読めること
- 画像、見出し階層、代替テキスト、フォーカス表示に重大な問題がないこと
